# Sound Library Tags

Static sound effects are deployed with the service under `Data/Sounds`.

Each tag directory may contain one or more WAV files. The sound-effect manager selects among the files for a tag.

## Alarm
- alarm
- alarm-warning
- timer
- reminder
- appointment

## Radio
- tuning
- scanning
- station-selected
- station-start
- station-stop
- station-up
- station-down

## News

- important
